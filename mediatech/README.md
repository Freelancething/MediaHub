# Adsy Media Partner Hub

A specialized marketing platform matching advertisers with website publishers and social media influencers to handle guest posts, link insertions, sponsored content, and brand shoutouts.

## Key Features

* **Role-Based Workflows**: Separate custom dashboards for Advertisers (Marketers), Publishers (Website Owners), and Influencers (Social Creators).
* **Publisher Platforms Manager**: Track site metrics (Domain Authority, traffic) and configure pricing packages.
* **Influencer Channel Manager**: Connect social handles (Instagram, TikTok, YouTube, X) and manage shoutout packages.
* **Unified Tasks Engine**: Seamless task progress lifecycle from review and acceptance through delivery, moderation feedback, and completion.
* **Transparent Wallet**: Real-time balance ledger, reserved funds escrows, and withdrawal status logs.
* **Integrated Referral Network**: Built-in tracking link builder with automated commissions processing.
